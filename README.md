## Ingeniera de Sistemas | Desarrolladora Web WordPress | Webmaster

Soy Ingeniera de Sistemas con experiencia en el desarrollo de sitios web corporativos, comerciales y de comercio electrónico utilizando WordPress. Me especializo en crear soluciones digitales enfocadas en rendimiento, experiencia de usuario (UX), optimización SEO y administración de contenido.
